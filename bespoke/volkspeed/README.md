# Volkspeed — T2 service enquiry, silver automotive presentation — v2

Client pitch concept, 24 September 2026. Five static pages: Home, Services, Our Expertise,
Workshops and Book a Service. No dependencies, video, third-party fonts or database.
Public entry: https://kites-studio.github.io/preview/volkspeed/

## Reuse

- Imports `../../shared/book.js` and its `enquiry.js` directly. The shared T2 engine is unchanged.
- `config.json` holds Volkspeed services, vehicle makes/models, branches and demo recipients.
- `site.js` adds menu/Escape, limited reveals, loading/error state, phone/name validation and
  branch opening-hour restrictions. It does not store data or send a message.
- No prices, ratings, guarantees or example perks copied from the generic auto skin.
- First-party logo and vehicle images from Volkspeed; three already-generated Higgsfield
  images reused from `assets/auto/`. Full provenance: `assets/volkspeed/SOURCES.md` in the private parent repo.
- Concept notice in footer flow, never a fixed overlay over form fields.

## Enquiry boundary

Vehicle → service → branch → preferred date/time → contact details → review → WhatsApp/email.
Both branches route to Kites 60102156826; email kites.stdio@gmail.com. The review explicitly
names Kites. Do not change only the number: update the demo wording at the same time.
No appointment is reserved, no payment taken, no enquiry stored. Nothing is sent until a
visitor chooses Send in their external messaging app.

## Editing

Edit the page source in `build.py`, then run `python3 build.py`. Styles and `site.js` remain
handwritten. Configuration is generated by the builder, so edit its source there. This is a
small authoring convenience, not a deployment requirement; GitHub Pages serves the HTML as-is.
Do not make a separate public repo: publish through the parent `kites-demos` subtree.

## QA

Five pages at 1440 / 768 / 390 / 320 pixels; no horizontal page overflow. Menu/Escape,
service + branch preselection, make/model/year, review/edit, encoded WhatsApp draft, Sunday
and Saturday constraints, reduced motion checked. No messages sent. Real Android hardware,
mobile-network timing and workshop availability are not tested or claimed.

## Redesign v2

User rejected the dark, condensed first design. Rebuilt all five pages with light silver/white surfaces, restrained red, DM Sans, large client-owned vehicle imagery, rounded photography and a functional opening enquiry panel. Both service and branch carry into T2. Mobile receives its own stacked opening. Original content and enquiry boundaries retained. One new image generation attempt hit the account usage limit; no generated output was used.
